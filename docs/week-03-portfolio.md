
# 15. Color Direction

The portfolio will use a professional dark-first visual style.

### Primary Background

Dark charcoal / near-black.

### Primary Text

White or near-white.

### Secondary Text

Muted gray.

### Accent

A single modern technology-oriented accent color such as blue or cyan.

### Usage Rule

The accent color will be used consistently for:

* Buttons
* Links
* Section highlights
* Icons
* Hover states
* Important metrics

I will avoid using many different colors because excessive colors can make a developer portfolio look inconsistent.

---

# 16. Typography

The typography will prioritize readability and modern technical aesthetics.

### Font Direction

Use a modern sans-serif font such as:

* Inter
* Poppins
* Space Grotesk

A monospace font may be used selectively for:

* Code-related elements
* Technology labels
* Small technical metadata

### Typography Hierarchy

```text
Large → Name / Hero Heading

Medium → Section Headings

Normal → Project and experience descriptions

Small → Dates / metadata / secondary information
```

The typography should remain readable on both desktop and mobile screens.
