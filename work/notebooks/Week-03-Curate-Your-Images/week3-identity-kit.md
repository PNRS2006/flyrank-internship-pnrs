# Week 3 — Decide Once: Build Your Identity Kit

## 1. Portfolio Visual Direction

### Design Goal

The portfolio should feel:

- Clean
- Technical
- Modern
- Confident
- Professional
- Understated

The design should frame the work rather than compete with it.

The projects, screenshots, dashboards, and technical evidence should be the most visually important elements on the page.

---

# 2. Typography

## Heading Font

**Space Grotesk**

Usage:
- Main hero heading
- Page headings
- Project titles
- Section headings
- Important labels

Recommended weights:
- 600 — Semibold
- 700 — Bold

Reason:

Space Grotesk gives the portfolio a modern technical character while remaining readable and professional.

---

## Body Font

**Inter**

Usage:
- Paragraphs
- Project descriptions
- Navigation
- Buttons
- Metadata
- Captions
- Supporting text

Recommended weights:
- 400 — Regular
- 500 — Medium
- 600 — Semibold

Reason:

Inter is highly readable across desktop and mobile interfaces and works well for technical/product-oriented content.
