## 4. Three Target Tasks

The following three tasks will be reused in the upcoming FL-02 through FL-04 assignments.

### Target Task 1 — DSA Problem Solving

**Purpose:**
Use AI as a collaborative assistant while solving DSA problems.

**AI assistance:**

* Understanding the problem
* Getting hints
* Identifying possible approaches
* Checking edge cases
* Debugging
* Comparing approaches
* Verifying complexity

**Definition of Done Well:**

I should be able to solve the problem correctly, explain the algorithm in my own words, state its time and space complexity, identify important edge cases and understand every part of the final implementation.

**Success Criteria:**

* The solution passes the required test cases.
* I can explain the approach without AI.
* I can state the time and space complexity.
* I can identify important edge cases.
* I can modify the solution when constraints change.

## 5. Key Learnings

This audit helped me understand that AI should not be used in the same way for every task.

For DSA and Machine Learning, AI is most useful as a collaborator. It can help me understand problems, identify mistakes, explore alternatives and improve my reasoning without replacing the learning process.

For repetitive activities such as documentation and initial content drafting, AI can save time by creating a first version that I review and personalize.

I also identified activities where AI should not replace me. College examinations, attending classes and making important personal or career decisions require my own responsibility and judgment.

The three workflows I selected — DSA problem solving, Machine Learning project development and internship assignment completion — will allow me to evaluate how AI can improve my productivity while maintaining my own understanding and decision-making.
